# catalog_agent

Агент, который собирает таблицу Excel установленного образца, извлекая
данные из нескольких исходных Excel-баз, где нужная информация разбросана
по разным листам и разным колонкам.

## Целевой формат

Одна строка = один товар (ключ — **артикул**), колонки:

```
артикул, модель, Наименование, Краткое техническое описание, Код ТНВЭД,
мнр, оис, Сертификат, начало, конец, ВЕС нетто, Вес брутто,
производитель, товарный знак, марка, страна происхождения, ЕД.измер
```

## Источники, которые умеет читать

1. **Каталог** — уже существующая база в целевом формате. Служит основой:
   из неё берутся поля, которые нельзя вычислить автоматически (мнр, оис,
   сертификат, даты действия, производитель, товарный знак, марка), а также
   уже известный код ТН ВЭД, если он там есть.
2. **Прайс-лист поставщика** — многостраничный файл, на каждом листе своя
   шапка (в разных строках, с разным набором и порядком колонок). Скрипт
   сам находит строку-шапку на каждом листе по наличию колонки «Артикул»
   и вытягивает: модель, наименование (берётся из колонки «Сегмент», если
   она есть — так эти данные организованы у поставщика), краткое
   техническое описание, вес нетто/брутто, страну происхождения.
3. **Реестр таможенных деклараций (ДТ)** — запасной источник кода ТН ВЭД,
   страны происхождения и единицы измерения по артикулу, если их ещё нет
   в каталоге.

Данные сливаются по приоритету: вручную выверенные поля — только из
каталога; технические данные — свежие из прайс-листа (если есть), иначе
из каталога; код ТН ВЭД и ед. измерения — из каталога, а если там пусто —
из реестра ДТ.

Позиции, для которых код ТН ВЭД так и не нашёлся, попадают в
дополнительный лист **«Проверить вручную»** в выходном файле — их нужно
досмотреть человеку.

## Запуск

```bash
pip install -r requirements.txt

python3 -m catalog_agent.cli \
  --catalog "Каталог.xlsx" \
  --pricelist "Pricelist_KZ.xlsx" \
  --customs "Реестр_ДТ.xlsx" \
  --output "Каталог_обновлённый.xlsx"
```

- `--pricelist` и `--customs` можно указывать несколько раз (несколько
  файлов-источников).
- `--catalog` не обязателен — если его не передать, каталог соберётся
  «с нуля» из прайс-листа и реестра ДТ (поля, доступные только вручную,
  останутся пустыми).
- `--articles path/to/list.txt` — ограничить обработку конкретным списком
  артикулов (по одному на строку), например только новыми позициями из
  последней поставки, а не пересобирать весь каталог целиком.

## Структура

- `catalog_agent/extract.py` — вся логика чтения источников и слияния
  данных.
- `catalog_agent/cli.py` — интерфейс командной строки.
